# 🛒 Amazon Product Analytics Dashboard

## 📌 About the Project
This interactive dashboard provides a comprehensive analysis of Amazon products, focusing on customer satisfaction, category performance, product popularity, and pricing strategies. 

## 📊 Key Metrics (KPIs) Analyzed:
- **Total Products:** 1,351
- **Total Reviews:** 1.67 Billion
- **Average Rating:** 4.1
- **Average Discount %:** 47.77%

## 🛠️ Tools Used:
Power BI / Python / SQL
- Data Cleaning & Transformation

## 💡 Key Insights:
- Detailed breakdown of reviews count by rating group and category.
- Correlation analysis between Average Rating and Average Discount %.
- Category and Sub-category drill-down capabilities.
